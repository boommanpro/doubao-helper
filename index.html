Usage

怎么用？打开一个 URL 就行

把内容编码进链接，豆包页面加载后自动填入并发送。以下三种方式任选。

基础调用 浏览器 / 书签
// 打开链接，自动翻译并发送 https://www.doubao.com/chat/?type=translate&content=Hello world
Raycast / Alfred macOS 快捷键
# 剪贴板文本一键翻译（脚本命令） open "https://www.doubao.com/chat/?type=translate&content=$(pbpaste)"
只填不发送 手动确认后发送
// 在配置面板关闭「自动发送」即可 https://www.doubao.com/chat/?type=polish&content=your%20text
省略 type 默认 translate
// 不传 type 时默认走「英文翻译」模板 https://www.doubao.com/chat/?content=some%20text
参数必填说明
type 否 提示词类型键名（translate / polish / summarize / explain …），省略时默认 translate
content 是 传给豆包的内容，建议做 URL 编码（空格 → %20）

FAQ

常见问题

打开 URL 后没有自动发送？

检查配置面板中「自动发送」是否开启。发送按钮未生效时脚本会依次回退 React onSubmit、模拟 Enter 键；仍失败可手动点击发送按钮。

刷新页面会重复发送吗？

不会。「发送后清理 URL 参数」默认开启，发送完成后地址栏参数会被移除，刷新不会重复触发。

自定义模板会丢失吗？

模板保存在油猴本地存储中。卸载脚本或清除站点数据会丢失，但内置模板可在配置面板一键「重置为默认」恢复。

content 里有特殊字符怎么办？

建议对 content 做 URL 编码（空格 → %20，& → %26）。配置面板会自动为每个模板生成可复制的编码 URL。
